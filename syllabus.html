Course Description

This module delves into advanced cloud architecture design principles, aligning with the AWS Certified Solutions Architect - Associate (SAA-C03) curriculum. Students will gain a comprehensive understanding of how to design and deploy secure, scalable, highly available, fault-tolerant, and cost-effective applications on AWS. Through hands-on labs and real-world case studies, students will develop the practical skills necessary to become proficient AWS cloud architects.

Learning Outcomes

By the end of this course, students will be able to:

  1. Analyse the main principles of cloud computing and how they have been implemented in modern cloud providers such as AWS
  2. Define a solution using architectural design principles based on customer requirements
  3. Assess various cloud architectures and implementations that solve common infrastructure issues
  4. Implement a cloud based architecture based on well designed architectural principles

Academic Integrity

Honesty and transparency are important features of good scholarship. On the flip side, plagiarism and cheating are serious academic offenses with serious consequences. If you are discovered engaging in either behavior in this course, you will earn a failing grade on the assignment in question, and further disciplinary action may be taken.

For a clear description of what counts as plagiarism, cheating, and/or the use of unauthorized sources, please see the University’s Policy on Academic Integrity in section 5.2 Plagiarism - Academic Integrity Policy of the Student Handbook

I encourage you to work together on homework assignments and to make use of campus resources like Learning Support to assist you in your pursuit of academic excellence. However, please note that you must acknowledge any collaboration or assistance that you receive on work that is to be graded: so when you turn in a homework assignments, please include a sentence at the end that says either:

  • “I worked alone on this assignment.”, or
  • “I worked with __________ on this assignment.” and/or
  • “I received assistance from _________ on this assignment.”

If you have questions about my integration of the university’s policy into this course, please do not hesitate to ask: my aim is to foster an environment where you can learn and grow, while ensuring that the work we all do is honest and fair.
